Independent review agents

A fresh mind before a consequential action

Four subagents the main agent delegates to. Each runs in its own clean context — the one thing a skill can’t give: independence. A review by the mind that made the call is self-review.

decision-reviewer
Red-teams the decision before it commits
Separates facts from assumptions, challenges false premises, confirms the risk class and approval requirement. Returns ready / not-ready.
Delegate at: any gate step, before a committing / destructive / outbound action.
scope-auditor
Checks blast radius against the evidence
Sizes both errors — under-scope (missed affected items) and over-scope (touching unaffected ones) — runs the population tie-out, checks salami exposure.
Delegate at: a cancel, a recall, a bulk write — the domain’s worst error is scope.
genealogy-tracer
Closes the lot genealogy + where-distributed map
Traces affected lots forward across ERP / PLM / WMS / TMS / CRM and returns one reconciled units-by-node map with its open gaps.
Delegate at: a recall, field action, or multi-tier shortage.
cross-system-reconciler
Resolves when two systems disagree
Pulls both readings, determines which system owns the fact, returns the reconciled value or an explicit halt — never averages the two.
Delegate at: on-hand vs WMS, ordered vs received, invoice vs GR vs PO.
They advise — they never decide
Each is fully tool-enabled and analysis-only by its prompt, not by disabling its tools. None owns safety: the deterministic gate enforces regardless of any agent’s verdict.
