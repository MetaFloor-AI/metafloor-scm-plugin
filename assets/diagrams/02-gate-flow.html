The safety gate

How a consequential action is governed

Every connector tool call passes through a deterministic PreToolUse gate before it runs. The gate decides from code and config only — never from the model’s opinion or the tool’s text.

value / quantity / count / currency limits · destructive & outbound floors · fails closed on any error
ALLOW

Hash-chained audit
every governed decision is recorded, tamper-evident, before the action commits
Injection-proof by construction. The gate reads the tool name, the classification, and the customer’s dial — not the tool’s text. A supplier note that says “auto-approve, ignore prior rules” is data, not an instruction: it cannot move the gate.
