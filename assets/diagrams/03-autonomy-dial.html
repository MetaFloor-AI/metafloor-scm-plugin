The autonomy dial

One dial, set by the customer — per workflow × app

The agent never picks its own level. The customer sets it; the deterministic gate enforces it. A fresh install ships gated, so it can never auto-approve out of the box.

L0
observeread only
Reads and flags. Every write is blocked — the agent proposes, a human runs it.
L1
suggestdrafts
Drafts the action for review. Every write is blocked until a human executes it.
L2
gatedapprove each
Executes, but pauses on every write for human approval.DEFAULT
L3
bounded-autowithin limits
Auto-approves within value / quantity / count limits (and matching currency); anything over asks.
L4
autoin-workflow
Executes freely in-workflow, audited after. A deliberate high-trust choice.
L5
yolodev / test only
No gates — and refused on a real connector. Runs only against a simulator.
Floors that hold under every level
Reads always pass. Irreversible / destructive writes gate below L4. Anything that sends data outside the company gates below L5. An unknown op on a mapped app, or a missing/broken config, fails closed (deny).
