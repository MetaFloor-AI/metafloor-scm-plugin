Safety boundary

What the gate governs — and what it doesn’t

The gate is a control you configure, not a guarantee. It governs the connector tools you map; declare every SCM app so its actions are covered.

Tool call
Outcome
Read on a mapped app
get / list / search
PASSAlways allowed
reads are never blocked
Write / destructive / outbound on a mapped app
GATEDPer the autonomy dial
an unknown op on the app → deny (fail closed)
Any op on an unmapped app
UNGOVERNEDUntil you declare it
run /scm-connectors to map it
Bash / curl / any non-mcp__ action
UNGOVERNEDOutside the gate
the gate governs mcp__* tools only
The gate is only as good as your connector map. Declare every SCM connector and classify each op (read / write / destructive / outbound); /scm-connectors echoes the classes back to confirm. An action taken outside a mapped connector runs under Claude Code’s own permissions.
